## 💡 Rekomendasi Format Gambar:
- Format file: `.png` (transparan/putih) atau `.jpg`
- Rasio aspek: 1:1 (persegi, misalnya 500x500 pixel atau 800x800 pixel)
- Jika gambar belum dimasukkan, aplikasi akan otomatis menampilkan ikon ilustrasi bawaan sebagai fallback yang aman tanpa error.
